# 樹木・植生調査アプリ

防災緑地などの樹木について、スマートフォン・タブレットで現地調査をするためのWebアプリです。**地上部調査**・**概況調査**・**植生調査**を記録し、Excelに出力します。通信のない場所でも使えます。

公園の樹木点検アプリの仕組み（地図・端末内保存・オフライン対応）を流用しています。植生調査は「植生野帳」の記録部分を参考にしています（解析機能は省いています）。

## ファイル

| ファイル | 内容 |
|---|---|
| index.html | アプリ本体（画面・プログラム・調査票の様式をすべて収録） |
| sw.js | オフラインで使うための仕組み（更新時は `VERSION` を変える） |
| manifest.webmanifest | ホーム画面に追加するための設定 |
| icon-192.png・icon-512.png | アイコン |

公開に必要なのはこの5ファイルです（README は任意）。

## 公開（GitHub Pages）

1. GitHub で新しいリポジトリ（Public）を作ります。
2. 「Add file → Upload files」で上の5ファイルをアップロードし、「Commit changes」を押します。
3. 「Settings → Pages」で Branch を `main`、フォルダを `/(root)` にして「Save」を押します。
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で開けます。

**樹木データ（Excel）や調査データ（ZIP）は、リポジトリにアップロードしないでください。** 樹木データは各端末で「出力・設定 → 樹木データを読み込む」から読み込みます。

## 使い方

1. 通信のある場所でページを開き、ホーム画面に追加します（アプリ本体が端末に保存されます）。
2. 「出力・設定 → 樹木データ様式」をダウンロードし、調査地・樹林の種類（広葉／針葉）・生育状況（良好／不良）・樹木番号・樹種・植栽基盤調査（有／無）・根系調査（有／無）・位置（緯度経度、または平面直角座標）を記入します。
3. 「樹木データを読み込む」でそのファイルを選びます。地図に「樹木番号_樹種」のラベルで表示されます。
4. 調査する範囲の地図を「オフライン用の地図」で保存しておきます。
5. 現地で木をタップして地上部調査、下のメニューから概況調査・植生調査を入力します。入力は自動で保存されます。評価基準などの解説は ⓘ を押すと表示されます。
6. 間違えて追加した木は、木の画面の「この木を削除」、または「地上部調査」一覧の「樹木を選んで削除」でまとめて削除できます。
7. 調査地を変えるときは「出力・設定 → ホーム画面に戻る」で調査地・調査員を選び直します。
8. 調査のたびに「写真・バックアップを含めてZIPで出力」で保管します。ほかの端末の記録は「バックアップを読み込む」で統合できます。

## 出力

| 出力 | 内容 |
|---|---|
| 地上部調査票（結果） | 様式「地上部調査票」に1本1シートで記入。集計表つき。写真は先頭6枚を写真欄に貼付 |
| 概況調査票（結果） | 様式「概況調査票」に調査地ごとに記入（調査区4列・備考） |
| 植生調査・一覧表 | 植生（調査区・出現種・素表・調査区ごとの調査票）、地上部・概況の一覧、樹木データ |
| ZIP | 上の3つ、すべての写真、バックアップ |

「植生_調査区」「植生_出現種」シートは植生野帳アプリの読み込み形式と同じ列です。

## 更新するとき

`index.html` を直したら、`index.html` の `version` と `sw.js` の `VERSION` を新しい番号にしてアップロードします。各端末はアプリを開き直すと新しい版に切り替わります。

**ホーム画面のアプリ（アイコン）は削除しないでください。** 端末内の調査データが消えることがあります。

## 様式を変えるとき

調査項目は `index.html` の `APP_CONFIG.surveys`、様式のExcelは末尾の `tplChijoB64`・`tplGaikyoB64`（base64）にあります。様式のセル位置を変えたときは、設定の `tpl`（セル番地）も合わせて変更してください。
